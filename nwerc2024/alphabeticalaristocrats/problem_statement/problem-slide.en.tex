    \begin{columns}
        \begin{column}[T]{.62\textwidth}
            \begin{itemize}
                \item Sort a list of $n\leq 1000$ Dutch surnames with lengths up to $50$ based on the Dutch rules,
                    lexicographically, according to the values of the ASCII characters.
                \item Consider only the part starting from the first capital letter.
                \item The surnames consist of English letters, spaces, and apostrophes
                    (\texttt{A-Z}, \texttt{a-z}, `\texttt{ }', `\verb|'|').
                \item It is guaranteed that the part starting with the first capital letter is unique.
                \item Names have no leading, trailing, or consecutive spaces.
                \item For example, the surname \texttt{van den Hecken the Younger} is sorted according to \texttt{Hecken the Younger}.
            \end{itemize}
