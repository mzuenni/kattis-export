        \begin{column}[T]{.70\textwidth}
            \begin{itemize}
                \item This is a multi-pass problem.
                \item In the first pass, you are given a string $s$ of length $n \leq 10\,000$ with only lowercase characters.
                    You need to transmit this string by using $5$ bitstrings, all of length at most $n+10$.
                \item In the second pass, you are given the $5$ bitstrings in arbitrary order, and you need to reconstruct the original string $s$.
            \end{itemize}
