    \begin{columns}
        \begin{column}[T]{.70\textwidth}
            \begin{itemize}
                \item There are $n\leq10^5$ people living in an apartment, but they only have $k$~($\leq n$) keys to share.
                \item If a person comes home while someone is home, they will be let in. \\
                    Otherwise, they need a key.
                \item Given the times when each person is out, determine when each person should take a key with them.
            \end{itemize}
