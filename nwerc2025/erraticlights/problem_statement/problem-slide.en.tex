        \begin{column}[T]{.70\textwidth}
            \begin{itemize}
                \item You have a string of $n \leq 100$ \texttt{r}ed/\texttt{g}reen/\texttt{b}lue lights.
                \item Every time you touch a light bulb, it randomly takes one of the three colours,
                    each with equal probability.
                \item You want the lights to have \emph{any} identical colour.
                \item What is the expected number of times you need to touch a light bulb
                    to make all of them have the same colour?
            \end{itemize}

            \vspace{1em}
            Example: Given two lights \texttt{rb}, an optimal strategy is to keep touching the first light until it turns blue. This takes $3$ steps on average.
