        \begin{column}[T]{.70\textwidth}
            \begin{itemize}
                \item You are given a permutation $(a_i)_{1 \le i\le n}$ of the numbers $1$ to $n \leq 5\cdot 10^5$.
				\item You want to turn it into a ``mountain-shaped'' permutation $(b_i)_{1 \le i\le n}$,
					meaning it is first increasing and then decreasing.
				\item You want to keep as many indices of the permutation the same,
                    so maximize the number of $i$ such that $a_i = b_i$.
				\item What is the smallest number of indices that need to change?
            \end{itemize}
