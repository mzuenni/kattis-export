    \begin{columns}
        \begin{column}[T]{.70\textwidth}
            \begin{itemize}
                \item You are given a road network (a tree) with $n \leq 10^5$ places, \\
                    and a set of $m \leq 5\cdot 10^5$ bridges connecting places from the tree.
                \item The roads have given lengths up to $10^6$, bridges have length $0$.
                \item Find the shortest tour that crosses all bridges, and uses each road at most once.
                    It is guaranteed that this is possible.
            \end{itemize}
