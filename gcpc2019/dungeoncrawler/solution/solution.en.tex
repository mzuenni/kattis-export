\begin{slide}
	\newcommand{\Map}[0]{\texttt{Map}}
	\newcommand{\Level}[0]{\texttt{Level}}
	\begin{block}{Problem}
		Check if two edge-labelled graphs (\Map\ and \Level) are identical ($\leadsto$ Graph isomorphism for special graphs).
	\end{block}
	\pause
	\begin{block}{Solution}
		\begin{itemize}
			\item Traverse \Level\ in DFS order to obtain the complete graph (usual backtracking with explicit \textit{Walk} instructions emitted).
			\item Find a bijective mapping between nodes in \Map\ and \Level:
				\begin{itemize}
					\item For each node in \Map, traverse \Map\ and \Level\ in parallel to construct a mapping.
					\item Detect inconsistencies in mappings (different edges for a node, non-bijective mapping, ...).
				\end{itemize}
			\item Number of remaining mappings determines the result.
			\item Pitfalls: All nodes have the same outgoing edges, but still a unique mapping is possible; \Level\ can be really large.
		\end{itemize}
	\end{block}
\end{slide}
