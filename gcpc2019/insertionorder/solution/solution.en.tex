\begin{slide}
  \begin{block}{Problem}
    Insert the numbers $\{1,\dots,n\}$ into an empty binary search
    tree in such an order that the final tree has height exactly $k$.
  \end{block}
  \pause
  \begin{block}{Solution}
    \begin{itemize}
      \item A solution exists if and only if $k \le n < 2^k$.
      \item First, build a binary tree with $n$ nodes and height $k$:
        \begin{itemize}
          \item Start with a degenerate tree that is just a path of
            length $k$.
          \item Then add nodes, making sure not to exceed height $k$.
        \end{itemize}
      \item Label the tree nodes $1,\dots,n$ from left to right.
      \item Output the labels from top to bottom.
      \item Many other approaches are possible.
    \end{itemize}
  \end{block}
\end{slide}
