\begin{slide}
  \begin{block}{Problem}
    Write a Tetris AI that is able to clear at least one row.
  \end{block}
  \pause
  \begin{block}{Insight}
    \begin{itemize}
      \item In this simplified game it is not possible to slide pieces
        under those already placed.
      \item So if the first piece is an \texttt{S} or \texttt{Z}, it
        becomes impossible to clear the first row.
      \item However, with the right orientation of pieces, it becomes
        easy to clear the second row instead:
        
        \centering
        \includegraphics[width=0.8\textwidth]{../problems/gameoffallingblocks/solution/oriented-pieces}
    \end{itemize}
  \end{block}
\end{slide}
\begin{slide}
  \begin{block}{Solution}
    \begin{itemize}
      \item Build the second row from left to right, always rotating
        the pieces appropriately.
      \onslide<5->{
        \item If the current piece is too wide, drop it on the left
          instead.
      }
    \end{itemize}
