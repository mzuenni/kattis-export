Some unspecified country wants to build a wall. Of course the wall must have the same height in all places (i.e. be rectangular), be as big as possible and it cannot have any holes that would let the evil people through, but its exact dimensions are not particularly important.

The stones needed to build the wall have already been ordered. They are all quadratic and their side length in meters is a power of two, but sadly, it is not the same power of two for all stones.

Given the sizes and quantities of the stones, calculate if it is possible to build a wall using all available stones, and if so, what length and height such a wall might have.


Input

The input consists of:
  - one line with an integer n (0 <= n <= 30), indicating that the largest stone has size 2^n.
  - one line with n + 1 integers m_0, ..., m_n, where m_i describes the number of stones of size 2^i that has been ordered.

It is guaranteed that the combined area of all stones is at most 10^16.


Output

If it is possible to build a rectangular wall without holes, output one line containing POSSIBLE and a second line containing two integers: the length and height of a possible wall that can be built.
Otherwise, output IMPOSSIBLE.
If multiple solutions exist, output any of them.


Sample Input 1

2
17 0 4

Sample Output 1

POSSIBLE
9 9
